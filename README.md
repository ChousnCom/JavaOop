# 클래스 
### 클래스는 객체를 설계하기 위한 틀 or 설계도임. 
### 클래스에 선언된 변수를 멤버변수라고 함.

# 객체
### 객체는 클래스에서 정의한 속성을 가진 실체, 객체는 서로 독립적인 상태를 가짐. 
```java
Student student1 = new student(); //x001
Student student2 = new student(); //x002
student1 = x001
student2 = x002
```
### new 를 통한 시점에서 객체가 생성됨.
### 이때 생성된 객체는 서로 독립적인 상태이므로 같은 클래스를 공유하여 사용하더라도 생성된 객체의 참조값은 다르게 담김.

```java
sutdent1.name = "학생1";
```
### 인스턴스에 접근하려면 .을 통해 해당 인스턴스의 멤버변수 접근 가능.

### 자바에서의 대입은 항상 변수에 들어 있는 값을 복사한다. 그래서 student1에는 참조값이 그대로 복사해서 대입.

# 기본형과 참조형

### 기본형(primitive Type) : int, long, double, boolean 처럼 변수에 사용할 수 있는 값을 직접 넣을 수 있는 데이터 타입.

### 참조형(Reference Type) : Student, int [] 등과 같이 데이터에 접근하기 위해 참조(주소)를 저장하는 데이터 타입을 참조형이라 부름. 

# 참조 vs 기본?

### 기본형 : 숫자 10,20과 같이 실제 사용하는 값을 변수에 당을 수 있음.
```java
int a = 10;
int b = a; //10
```
### a는 10이라는 값을 복사해서 대입하는 것, 이때 b도 a를 그대로 대입하는 것이 아닌, a의 값을 복사해서 대입하는 것. 

### 기본형은 들어 있는 값을 그대로(+,-,*,/)과 같은 계산에 그대로 사용가능

### 기본형은 메서드 내부에서 파라미터 값을 변경하여도 메서드 내부에서만 잠시 값이 변경 될 뿐, 호출자의 변수 값에는 영향x

### 참조형 : 실제 사용하는 값을 변수에 담는 것이 아닌, 실체 객체의(참조, 주소)를 저장
```java
Data data = new Data(); //x001
```
### 참조형은 변수값에 참조값을 저장, 이때 객체는 .을 통해서 메모리상에 생성된 객체를 찾아가야 사용 가능.

### 참조형은 주소값을 담는 것으로, 그대로는 사용x 주소지에 가야 실체가 있음.

### 참조형은 메서드 호출시, 참조값이 복사되어 전달 -> 메서드 내부에서 파라미터로 전달된 객체 멤버 변수를 변경하면 호출자의 객체도 변경 됨.
```java
Data data = new Data();
data.value = 10;

static void changeReference(Data dataX){
   dataX.value = 20;
}
```
### 이 메서드를 호출하면 값이 20으로 변경


# 변수의 초기화

### 참조형의 변수 값 초기화는 자동 즉, 멤버 변수의 초기화는 자동으로 이뤄짐.
### 반면 지역 변수의 초기화는 수동으로 초기화 해야함.

# null

### 참조형 변수에서 아직 가리키는 대상이 없다면 null이라는 특별한 값을 넣어 둘 수 있음.
### null은 아직 값이 존재하지 않는 없다는 뜻.

### 아무도 참조하지 않는 인스턴스는 사용되지 않고 메모리 용량만 차지 -> 이때 JVM이 GC를 사용해서 제거

# NPE(NullPointerException)
### 주로 .을 찍어 참조값이 null인 객체에 접근할때 발생.
### 참조를 해야하는 주소값이 존재하지 않으므로 해당 주소를 찾아갈 수 없기 때문에 발생.
